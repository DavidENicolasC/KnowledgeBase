Create the project depending on the used tool.

Toolkit that will enable engineering teams to rapidly scaffold out a new `tauri-apps` project using the frontend framework of their choice (as long as it has been configured).

For Linux and MacOS:
```
sh <(curl https://create.tauri.app/sh)
```

For Windows:
```
irm https://create.tauri.app/ps | iex
```

After that, [[Scaffold the project with create-tauri-app]]

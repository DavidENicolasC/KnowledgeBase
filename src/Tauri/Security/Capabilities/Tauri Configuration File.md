It's the `tauri.conf.json` file.

Is used by the [[Tauri runtime]] and the [[Tauri CLI]].

Is used to define the source of your Web app, describe your application’s metadata, configure bundles, set plugin configurations, modify runtime behavior by configuring windows, tray icons, menus and more.

You can define build settings (such as the [command run before `tauri build`] or [`tauri dev`], set the `name` and [[Tauri app version]], [[Tauri runtime control]], and [[Tauri plugin configuration]].

Default [[Tauri]] config format is JSON.

You can [[Enable other formats for the Tauri Configuration File]].
